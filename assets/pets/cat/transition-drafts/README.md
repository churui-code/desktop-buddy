# 提起与放下关键帧草图

这些素材由内置 imagegen 参考原始待机猫生成，原始 RGBA PNG 保持不变，完整提示词保存在同名 `.prompt.txt` 中。已通过 `CatTransitionFrames` 接入运行时，当前是少量关键帧的审阅版本。

| 素材 | 动作 |
| --- | --- |
| `pickup-early-v2.png` | 刚离地：抬前爪，后腿仍收在两侧 |
| `pickup-middle-v2.png` | 半展开：打开髋部，后腿仍弯曲 |
| `pickup-late-v1.png` | 接近悬空：前后爪下垂，身体伸长 |
| `landing-contact-v1.png` | 放下收尾：四爪着地，身体轻压 |

## 当前接入方式

- 待机与悬空的持续摇摆仍使用现有分层素材；提放过程改为少量关键帧。
- 提起：原始坐姿 → 刚离地 → 半展开 → 接近悬空 → 分层悬空。
- 放下：反向复用提起帧 → 着地压缩 → 原始坐姿。帧停留时间独立设置，放下后继续惯性衰减。
- 保持原始头部和眼睛图层，只使用关键帧中的身体区域。源图脖颈锚点分别为 (627,752)、(627,650)、(627,570)、(627,790)，以像素计。
- 按头部和胸口的尺寸校准，保持素材比例。悬空自然比坐姿更高，不按整猫包围盒高度缩放，不拉伸到同样的矩形。
- 统一较大的透明画布并记录关节锚点；需要更多空间时扩大透明窗口留白，保留猫本身的尺寸。
- 三张过渡帧是关键姿势草图。当前直接切换身体帧并连续移动头颈，后续仍可在相邻姿势之间补帧；没有使用整图透明交叠。运行时预览：`previews/cat-drag-swing-v5.webp`。

## 比例审阅

`draft-manifest.json` 记录尺寸、透明像素、可见边界和头宽估计。前两张和着地帧的头宽约 742–744 像素，接近悬空帧约 644 像素。运行时用 1.0、743/742、743/644、743/744 的等比缩放校准身体，头部始终使用未缩放的原始头层；这组图仍不是完整连续帧。

运行 `--script res://scripts/export_transition_drafts_preview.gd` 输出 `previews/cat-transition-keyframes-v1.png`。该图只为审阅而按头宽估计等比显示，保留各姿势的不同身高，不修改源 PNG。
