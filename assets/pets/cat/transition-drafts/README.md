这些素材由内置 imagegen 参考原始待机猫生成，原始 RGBA PNG 保持不变，完整提示词保存在同名 `.prompt.txt` 中。当前用于姿态和比例审阅，尚未接入运行时。

## 建议接入方式

- 待机与悬空的持续摇摆仍使用现有分层素材；提放过程改为少量关键帧。
- 提起：原始坐姿 → 刚离地 → 半展开 → 接近悬空 → 分层悬空。
- 放下：反向复用提起帧 → 着地压缩 → 原始坐姿。帧停留时间独立设置，放下后继续惯性衰减。
- 保持原始头部和眼睛图层，只使用关键帧中的身体区域，避免每次生成的脸发生变化。头颈位置需要逐帧标定。
- 按头部和胸口的尺寸校准，保持素材比例。悬空自然比坐姿更高，不按整猫包围盒高度缩放，不拉伸到同样的矩形。
- 统一较大的透明画布并记录关节锚点；需要更多空间时扩大透明窗口留白，保留猫本身的尺寸。
- 三张过渡帧是关键姿势草图。真正接入时需在相邻姿势之间补帧，并用直接帧播放检查连贯性，避免重新使用整图透明交叠代替动作。

## 比例审阅

`draft-manifest.json` 记录尺寸、透明像素、可见边界和头宽估计。前两张和着地帧的头宽约 742–744 像素，接近悬空帧约 644 像素，说明生成仍有尺寸漂移；它需要按头宽等比校准，再与原始头层对齐，不能直接作为已完成的连续帧。

运行 `--script res://scripts/export_transition_drafts_preview.gd` 输出 `previews/cat-transition-keyframes-v1.png`。该图只为审阅而按头宽估计等比显示，保留各姿势的不同身高，不修改源 PNG。
